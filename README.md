# Deep Learning Lab — Google Colab Notebook Pack

Based on the 8 experiments listed in the uploaded VTU Deep Learning Lab Manual.

| Program | Notebook |
|---|---|
| 1 | `01_Word_Embeddings_Word2Vec.ipynb` — Word Embeddings using Word2Vec |
| 2 | `02_Deep_Neural_Network_Iris.ipynb` — Deep Neural Network for Iris Classification |
| 3 | `03_CNN_MNIST_Classification.ipynb` — CNN for MNIST Image Classification |
| 4 | `04_MNIST_Autoencoder_Compression.ipynb` — Autoencoder for Image Compression |
| 5 | `05_IMDB_Text_Document_Classification.ipynb` — Deep Learning for Text Document Classification |
| 6 | `06_LSTM_Time_Series_Forecasting.ipynb` — Time Series Forecasting using LSTM |
| 7 | `07_Transfer_Learning_MobileNetV2_CIFAR10.ipynb` — Transfer Learning with Pre-trained MobileNetV2 |
| 8 | `08_TFIDF_Logistic_Review_Sentiment.ipynb` — Positive and Negative Review Classification |

## Run instructions
1. Upload/open each `.ipynb` file in Google Colab.
2. Select Runtime → Change runtime type → GPU for image/deep-learning experiments.
3. Run all cells from top to bottom. Internet access is needed to download datasets / pretrained weights.
4. Outputs are saved under `/content/DL_Lab_Outputs/Program_n`.
5. Use the download cell in `outputs/README_OUTPUTS.txt` to download generated artifacts.
