## 🚀 About This Repository

Welcome to **Deep Learning Lab**, a practical collection of eight deep learning experiments developed as part of the **7th Semester B.E. – Computer Science and Engineering (Artificial Intelligence & Machine Learning)** curriculum.

This repository explores how neural networks learn patterns, understand images, process natural language, compress information, and make predictions.

Every experiment is provided as an individual **Google Colab Jupyter Notebook (`.ipynb`)**, with explanatory comments throughout the code to make implementation and learning easier.

> **Learn by implementing. Understand by experimenting. Build by exploring.**

## 🔬 Experiments at a Glance

### 01 — Word Embeddings
Generate numerical word representations using Word2Vec and explore semantic similarities between words.

### 02 — Deep Neural Network
Build a multi-layer neural network to classify the Iris dataset into different flower categories.

### 03 — Convolutional Neural Network
Develop a CNN model for handwritten digit recognition using the MNIST dataset.

### 04 — Autoencoder
Implement an encoder-decoder architecture to compress image data and reconstruct the original images.

### 05 — Text Classification
Apply embedding layers and neural networks to classify IMDB movie reviews.

### 06 — Time Series Forecasting
Use LSTM networks to learn sequential patterns and forecast future values from time-series data.

### 07 — Transfer Learning
Apply the pre-trained MobileNetV2 architecture to CIFAR-10 image classification.

### 08 — Sentiment Analysis
Classify text reviews as positive or negative using TF-IDF feature extraction and Logistic Regression.

## ⚡ Getting Started

### Option 1: Run using Google Colab

1. Clone or download this repository.
2. Open the required `.ipynb` notebook.
3. Upload it to [Google Colab](https://colab.research.google.com/).
4. Select **Runtime → Change runtime type**.
5. Choose GPU for computationally intensive experiments.
6. Execute the notebook cells sequentially.

### Option 2: Run using VS Code

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Deep-Learning-Lab.git
```

Navigate to the project:

```bash
cd Deep-Learning-Lab
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow gensim
```

Open the folder in VS Code:

```bash
code .
```

Install the Python and Jupyter extensions, open any notebook, and select the appropriate Python kernel.
